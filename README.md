# Анализ A/B-эксперимента

Сгенерированные уникальные данные: `experiment_data.csv` (SEED 3523534, 9725 пользователей).

Файлы:
- `ab_experiment_audit.ipynb` — полностью выполненный ноутбук с результатами и графиками.
- `experiment_data.csv` — уникальный датасет для проверки.
- `analyze_experiment.py` — отдельный Python-скрипт для аудита.
- `generate_data.py` — код однократной генерации (повторный запуск создаст **новый** файл и перезапишет датасет!).

## Запуск

```bash
pip install numpy pandas scipy matplotlib seaborn statsmodels scikit-learn nbformat notebook
jupyter notebook ab_experiment_audit.ipynb
# или:
python analyze_experiment.py
```

Выполнять из папки с файлами. В генераторе **намеренно изменены** разрешённые параметры: диапазон количества пользователей `[9000,10000)` и `prob_test = clip(0.36 + 0.55 * pre_activity / pre_activity.max(), 0, 1)` вместо `0.4 + 0.3*x`. Строка с первоначальным распределением 40/60 перезаписывается последующим присваиванием, как в оригинальном коде.

**Итог:** обнаружены SRM, дисбаланс pre_activity и ухудшение частоты ошибок. Эксперимент невалиден. Коррекция IPW демонстрируется только как диагностический метод и не заменяет перезапуск.
